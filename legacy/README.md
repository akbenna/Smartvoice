# Legacy

`briefassistent/` is de losse BriefAssistent-extensie (v4), met volledige
git-geschiedenis hierheen gehaald. Hij is vervangen door het tabblad
**Brieven** in `chrome-extension/` (SmartVoice 2.0). De code blijft hier
alleen als naslag; laad hem niet meer als extensie. Hij bewaarde een
Anthropic-sleutel in de browser, en de nieuwe versie doet dat niet meer.
